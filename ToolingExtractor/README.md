## Quick run

From the repository root:

```bat
run.bat
```

Or from this folder:

```powershell
dotnet run --project src/ToolingExtractor.Web
```

Or change directory to the web project:

```powershell
cd src/ToolingExtractor.Web
dotnet run
```

Open the URL printed in the console (e.g. `http://localhost:5261`).
